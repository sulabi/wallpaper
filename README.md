# Wallpaper

### What is this?
A comfort tool that searches for and sets wallpapers through existing wallpaper setters.

I plan to make a wallpaper setter and searcher, for my desktop use.
I will not be making a wallpaper setter from scratch, this is a wrapper around existing setters.

### Some goals:
* Crossplatform compatibility (Linux, MacOS, Windows)
* Create a UI for the application
* Create a small db for wallpapers saved, containing wallpaper information.
* Create a configuration for how users should set the wallpaper
